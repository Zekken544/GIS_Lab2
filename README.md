# Лаборатори 2 · Python үндэс ба файл боловсруулах

- **3.8** — python sums.py. 1–100 хүртэлх нийт, сондгой, тэгш тооны нийлбэр 5050, 2500, 2550. range-ийн төгсгөлийн утга орохгүй тул 101 хэрэглэнэ.
- **4.6.1** — python points.py. Гурван цэгийн гурван хосыг нэг давталтаар, дурын тооны цэгийн хос бүрийг давхар давталтаар шалгана. Жишээний хамгийн их зай 5 ба 10.
- **4.6.2–4.6.4** — python file_io.py. Жишээ текст файлыг үүсгэж уншина, координатыг хэвлэнэ, цэгийн объектуудын хоорондох хамгийн их зайг result.txt файлд бичнэ. Өөрийн өгөгдөлтэй ажиллуулахдаа python file_io.py points.txt result.txt гэж ажиллуулна.
- **Файлын бүтэц** — point: толгойн дараа p1: 1.0, 1.0 хэлбэрээр нэг мөрөнд нэг цэг бичнэ. Мөн point; толгойтой нэр; x, y хэлбэр болон point: толгойн дараах 1.0, 1.0; 2.0, 2.0 хэлбэрийг уншина. Сүүлийн хэлбэрт нэр автоматаар үүснэ.
